## 2024-04-24 - Extracting UI helper methods to classes
**Learning:** In Flutter, UI-building helper methods (e.g., `_buildWidget()`) execute during every parent rebuild. Refactoring them into dedicated private `StatelessWidget` classes is a recommended architectural best practice because it improves `BuildContext` scoping and element tree management. However, extracting to a widget does *not* inherently skip rebuilding the sub-tree. Without `const`, Flutter will still call the `build` method of the child widget whenever the parent rebuilds. You must instantiate the widget with the `const` keyword to actually instruct the framework to skip rebuilding those widgets.
**Action:** When optimizing static UI mockups, extract `_buildHelper` methods to `StatelessWidget` classes and ensure you instantiate them with `const` at their call sites (e.g., `const _FileItem(...)`) when all arguments are static to prevent unnecessary widget rebuilds.
