## 2026-04-17 - [Extract Helper Methods to const StatelessWidget]
**Learning:** In Flutter, UI-building helper methods (e.g., `_buildWidget()`) execute during every parent rebuild. Refactoring these methods into dedicated private `StatelessWidget` classes and instantiating them with the `const` keyword allows the Flutter framework to completely skip the build phase for these sub-trees when the parent rebuilds. This is a crucial codebase-specific optimization for complex UIs that might rebuild frequently.
**Action:** When auditing Flutter screens for performance, aggressively look for `_build...` helper methods that depend only on primitive or immutable parameters and refactor them into `const StatelessWidget` classes. Ensure all call sites are updated to use the `const` keyword.
