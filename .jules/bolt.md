## YYYY-MM-DD - [Navigation Stack Memory Leak]
**Learning:** [Using pushNamed repeatedly for root-level navigation (like inside a BottomNavigationBar) creates an unbounded route stack and memory leaks. In Flutter, replacing Navigator.pushNamed with Navigator.pushNamedAndRemoveUntil(..., (route) => false) for tab navigation destroys the entire navigation stack and introduces a major functional regression by breaking expected back-button behavior. Reserve pushNamedAndRemoveUntil for clearing the stack after login. Use pushReplacementNamed for tab switches.]
**Action:** [Replaced Navigator.pushNamed with Navigator.pushReplacementNamed for root-level navigation (like BottomNavigationBar switches) to keep the stack flat. Replaced Navigator.pushNamed with Navigator.pushNamedAndRemoveUntil for post-login screens to prevent returning to the login screen.]
