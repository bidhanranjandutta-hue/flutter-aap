## YYYY-MM-DD - Route Stack Leak Optimization
**Learning:** Found an anti-pattern in the bottom navigation. The app uses `Navigator.pushNamed(context, '/dashbord');` from sub-tabs to return to the root dashboard tab. In a `BottomNavigationBar` setup, this pushes a new dashboard route onto the stack instead of popping existing ones, creating an unbounded route stack memory leak. Similarly, the Welcome screen uses `pushNamed` for a one-way login transition, keeping the welcome screen alive in memory unnecessarily.
**Action:** Replace `Navigator.pushNamed` with `Navigator.pushNamedAndRemoveUntil` when returning to the root tab (`/dashbord`) or making one-way root transitions (like login). Note: When navigating away from the dashboard tab into sub-tabs, `pushNamed` should be preserved to maintain correct back-button behavior, as the dashboard is the root.
