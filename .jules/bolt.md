## 2024-05-14 - Refactoring UI-building methods into const StatelessWidgets
**Learning:** In Flutter, UI-building helper methods like `_buildFileItem(context, ...)` execute entirely within the parent widget's build method, causing the entire subtree to rebuild whenever the parent updates. Converting these heavily reused methods into dedicated private `StatelessWidget` classes (e.g. `_FileItem`) and instantiating them with the `const` keyword allows the Flutter framework to skip the build phase entirely for these sub-trees when the parent rebuilds. This is a crucial codebase-specific optimization to prevent unnecessary widget rebuilds and layout thrashing, which is especially important for lists of items inside scrollable views.
**Action:** When searching for performance opportunities, look for frequent `Widget _buildXYZ(BuildContext context, ...)` methods. Refactor them into standalone `StatelessWidget` classes and replace call sites with `const` instantiations to reduce widget rebuild cycles.
