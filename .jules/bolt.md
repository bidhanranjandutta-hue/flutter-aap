## 2024-06-14 - Navigation Memory Leak Discovery
**Learning:** Found an unbounded navigation route stack memory leak when navigating repeatedly from bottom navigation bar in `lib/screens/dashboard_screen.dart` using `Navigator.pushNamed`. This is an architecture-specific performance bottleneck in Flutter applications that causes memory to grow over time by adding identical routes to the stack.
**Action:** Replace `Navigator.pushNamed(context, '/ocr')` in the BottomNavigationBar's `onTap` with `Navigator.pushNamedAndRemoveUntil(context, '/ocr', (route) => false)` to avoid growing the stack when using root-level navigation tabs. However, we should verify the specific requirements. Since the bottom navigation bar is present on the Dashboard, but maybe not on the OCR screen, the best way to handle returning to the root tab is to clear the stack up to the dashboard. But wait, typically if you go to a sub-tab, you want to come back. The memory says: "In Flutter, using `Navigator.pushNamed` repeatedly for root-level navigation (like inside a `BottomNavigationBar`) creates an unbounded route stack and memory leaks. To fix this while preserving back-button behavior, navigate away from the root tab (e.g., dashboard) using `pushNamed`, and return to the root tab using `Navigator.pushNamedAndRemoveUntil(..., (route) => false)`."
