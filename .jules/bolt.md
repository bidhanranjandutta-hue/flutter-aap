## 2024-05-14 - Optimize Static Mock UI with const StatelessWidget
**Learning:** In Flutter screens with primarily static mockups (e.g., Law Map Screen), prioritizing the refactoring of large UI-building helper methods into `const StatelessWidget` classes is safer and more effective than attempting to isolate localized state with `ValueNotifier`. The latter risks architectural state regressions, while `const` widget instantiation allows the framework to completely skip the build phase for those sub-trees without side effects.
**Action:** When optimizing primarily static screens that use `setState`, search for UI-building helper methods and refactor them into dedicated private `StatelessWidget` classes. Ensure all call sites are explicitly updated to instantiate them with the `const` keyword.
