## 2024-05-15 - Extracted Static Law Cards into `const StatelessWidget`
**Learning:** In Flutter, UI-building helper methods like `_buildLawCard` are executed during every parent rebuild (e.g., when toggling segments or typing). Because `_buildLawCard` does not depend on local state but only pure arguments, extracting it into a `const StatelessWidget` named `_LawCard` allows Flutter's element tree to skip rebuilding those widget subtrees entirely when instantiated with `const`. This minimizes unnecessary CPU cycles and object allocations during interactions on a primarily static mockup screen.
**Action:** When optimizing Flutter screens dominated by static views, prioritize extracting large, static `_buildHelper` methods into `const StatelessWidget` classes rather than introducing complex state management like `ValueNotifier`. Ensure the refactoring removes `BuildContext` from properties and correctly handles `const` constructor instantiations at all call sites.
