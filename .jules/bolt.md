## 2026-05-05 - Flutter Rebuild Performance Optimization
**Learning:** Extracting UI-building helper methods (like `_buildLawCard` in `law_map_screen.dart`) that return complex widget trees into dedicated private `StatelessWidget` classes instantiated with the `const` keyword allows the Flutter framework to completely skip their build phase when the parent `StatefulWidget` rebuilds (e.g., via `setState`). In `law_map_screen.dart`, `setState` is called to switch segments, which previously forced the entire list of `_buildLawCard` results to be unnecessarily rebuilt.
**Action:** When a `StatefulWidget`'s `build` method is large and frequently rebuilt via `setState`, refactor its expensive or repeating helper builder methods into `const StatelessWidget` classes to minimize the rebuild scope and optimize performance.
