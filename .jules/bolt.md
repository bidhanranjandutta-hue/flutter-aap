## 2024-05-03 - Flutter Rebuild Optimization via Const Widgets
**Learning:** In Flutter, UI-building helper methods (e.g., `_buildWidget(context, ...)`) execute entirely during every parent rebuild. To optimize performance and reduce memory allocation per frame, these methods should be extracted into dedicated private `StatelessWidget` classes and instantiated with the `const` keyword. This signals the Flutter framework to completely skip the build phase for these sub-trees when the parent rebuilds. Simply extracting to a widget does not inherently skip rebuilds; the `const` instantiation at the call site is strictly required to achieve the performance benefit.
**Action:** Identify helper methods returning stateless widgets. Refactor them into standalone `StatelessWidget` classes, remove `context` as a parameter (since `build` provides it), ensure all constructor fields are `final` and non-closure so the widget can be instantiated with `const`, and update call sites to use `const _ExtractedWidget(...)`.
