## 2024-05-12 - Prevent Re-instantiating Disposable Controllers in build()
**Learning:** Creating `TextEditingController` directly within a widget's `build` method is a critical anti-pattern in Flutter. The `build` method can execute up to 60 times per second during animations or state updates. Each execution creates a new controller object that is never disposed, resulting in runaway memory leaks, loss of user input state between frames, and excessive garbage collection pauses.
**Action:** Always extract disposable objects (like `TextEditingController`, `AnimationController`, `ScrollController`) into stateful variables. Initialize them in `initState()` and explicitly call `.dispose()` on them within the widget's `dispose()` lifecycle method to ensure proper memory management and UI consistency.
