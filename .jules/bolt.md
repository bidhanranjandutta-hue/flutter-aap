## 2024-05-07 - Refactoring Flutter UI helper methods to const StatelessWidget
**Learning:** Extracting `_buildWidget` helper methods that depend on `BuildContext` and dynamic callbacks to `const StatelessWidget` improves performance, but using Python scripts for this requires very careful string processing. `replace_with_git_merge_diff` and regexes can fail easily with Dart's multi-line strings, whitespace differences, and string literal escape bugs. Python `replace` is safe if the string chunk exactly matches, but even `r""` can struggle if raw quotes get mistakenly escaped.
**Action:** Always prefer parsing exact chunks of code via manual multi-line `replace()` over complex regexes when writing Python refactoring scripts for Dart. When replacing widget methods, carefully trace opening and closing braces with simple state machines to avoid accidentally truncating or skipping code.
