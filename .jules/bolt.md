## 2024-05-18 - Extracting Flutter UI Builders to Const StatelessWidgets
**Learning:** In Flutter, UI-building helper methods (like `_buildWidget()`) execute during every parent rebuild. When a StatefulWidget's state changes (like selecting a segment in `LawMapScreen` using `_selectedSegment`), all helper methods are re-executed, rebuilding their entire sub-trees even if their content hasn't changed.
**Action:** Always refactor these static helper methods into dedicated private `StatelessWidget` classes and instantiate them with the `const` keyword. This allows the Flutter framework to completely skip the build phase for these sub-trees when the parent rebuilds. Note that extracting to a widget does not inherently skip rebuilds; the `const` instantiation at the call site is strictly required to achieve the performance benefit.
