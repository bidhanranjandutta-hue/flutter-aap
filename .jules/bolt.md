## 2025-10-24 - Flutter Widget Extraction Performance
**Learning:** In Flutter, UI-building helper methods (like `_buildInfoBox`) execute during every parent rebuild, which is inefficient. Extracting them into dedicated private `StatelessWidget` classes does not automatically skip rebuilds; they must be explicitly instantiated with the `const` keyword at their call sites to achieve the performance benefit of completely skipping the build phase for that sub-tree when the parent rebuilds.
**Action:** When extracting Flutter widget helper methods into `StatelessWidget` classes to optimize performance, ensure the new class is instantiated with `const` at all call sites, and correctly remove `context` from the new class's constructor properties since it is natively provided via the `build` override.
