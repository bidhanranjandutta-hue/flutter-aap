## YYYY-MM-DD - [BottomNavigationBar Navigation Stack Memory Leak]
**Learning:** [In Flutter, using `Navigator.pushNamed` for root-level navigation (like inside a `BottomNavigationBar` onTap) creates an unbounded route stack and memory leaks. Every time a user switches tabs, a new instance of the screen is pushed onto the stack. Furthermore, replacing `pushNamed` with `pushNamedAndRemoveUntil(..., (route) => false)` destroys the entire navigation stack and breaks expected back-button behavior.]
**Action:** [Use `Navigator.pushReplacementNamed` to keep the stack flat during tab switches, which avoids unbounded stacks while preserving back-button behavior for non-root routes. Keep using `pushNamed` for hierarchical views, and reserve `pushNamedAndRemoveUntil` for un-returnable flows like post-login screens.]
